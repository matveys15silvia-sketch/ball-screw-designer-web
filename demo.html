Ball Screw Designer — настольная версия

Скриншоты приложения для Windows (PySide6). Анализ STEP-моделей, 3D и инерционный анализ работают только в настольной версии; расчёт и подбор ШВП доступен в веб-версии. Значения — пример на тестовой сборке, сгенерированной программой; J ротора задан для проверки, не из каталога двигателя.
