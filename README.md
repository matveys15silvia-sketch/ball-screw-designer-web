# Ball Screw Designer — веб-версия

Предварительный подбор шарико-винтовых передач (ШВП) для станочных осей прямо в браузере
(телефон, планшет, компьютер). Методика: каталог HIWIN «Ballscrews & Accessories»
BS-08-2-EN-1704-K, разд. 3.7 (DIN ISO 3408).

Проверяется: частота вращения и DN, критическая частота, устойчивость при сжатии,
статический запас S0, ресурс L10 (об, км, ч) по фазам цикла с учётом натяга и надёжности,
момент и мощность привода, размещение хода и гайки, длина вала, люфт, точность, жёсткость (оценка).
Статусы: «Подходит», «Условно подходит», «Недостаточно данных», «Не подходит».

База: 330 типоразмеров из официального каталога HIWIN (2017) с указанием таблицы и страницы.
Неизвестные характеристики не подставляются. Расчёт предварительный; значения и выбор
подтверждайте у производителя. Сравнение с официальным калькулятором HIWIN не выполнялось.

Файлы генерируются из основного проекта (`web/`, `tools/build_web.py`); расчётное ядро
`core.js` автоматически сверяется с Python-ядром настольной программы.
